# 2026-10-05 项目版本快照

版本：**2026.10.5**。分支：`codex/research-2026-10-05`。这是当前研究项目的 GitHub 快照，不是生产交易发布，也不修改既有 v3/v4/v5 模型命名。

## 模型状态与已知问题

整体模型架构设计已完成较多尝试，包括多尺度因果编码、TCN/GRU、字段适配、收益与路径辅助监督、监督几何与共享梯度预算、多种子、共同市场/币种增量读出，以及成熟折外校准和基线比较。具体方法、负面结果和研究边界保留在各代报告中，不只上传表现最好的一种方案。

**当前项目在部分时段的模型预测仍有问题。** 预测方向与幅度的稳定性、月份/市场状态迁移、幅度校准和相对排序都还存在限制；部分校准时段相对信息被明显收缩，部分弱预测组在后续历史中的实现响应不佳。模型架构的多轮尝试不等同于已经证明稳定、可迁移的预测优势。策略历史正收益也不能单独证明模型信息质量或新增 alpha；既有后续历史已被反复查看，不重新称为独立前瞻测试。
